# Security policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** form in the repository Security
tab. That private channel is the supported way to report suspected security or
privacy issues. Do not open a public issue or include live credentials,
personal data, exploit details, or affected venue information in public.

Include the affected surface, reproduction steps, impact, and any suggested
mitigation. Receipt and remediation timelines depend on severity and project
availability; this portfolio project does not promise a public SLA or bug
bounty.

## Scope

Only the latest published mirror revision is in scope. Third-party services,
social engineering, denial-of-service testing, automated traffic against a
live venue, and access to data that is not your own are out of scope.

If a credential is discovered in repository history, treat it as compromised
and report it privately so it can be revoked before source cleanup.
