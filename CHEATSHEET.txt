== 3. STOP THE APP
  Ctrl+C                               # backend + frontend; Docker keeps running
  ./scripts/stop.sh                    # also Docker (removes containers, keeps data)

  cd server && docker compose stop
  cd server && docker compose down
  cd server && docker compose up -d

== 4. SEED / RESET DEMO DATA            (destroys the demo tenant's changes)
Stop the API first or the seed blocks on a lock:
  pkill -f "uvicorn app.main:app"

  cd /Users/rodinkaradeniz/projects/crowbar
  SEED_DATA=true ./scripts/dev.sh
  SEED_DATA=true DEMO_ADMIN_PASSWORD='your-password' ./scripts/dev.sh

Reseed without restarting (Docker up, API stopped):
  cd /Users/rodinkaradeniz/projects/crowbar/server
  SEED_DATA=true venv/bin/python -m db.migrate

Migrations only:
  cd /Users/rodinkaradeniz/projects/crowbar/server
  venv/bin/python -m db.migrate

== 5. KILL A PROCESS ON A PORT
  lsof -i :3000
  lsof -ti :3000 | xargs -r kill
  lsof -ti :3000 | xargs -r kill -9
  lsof -ti :3000 -i :8000 | xargs -r kill

Target the port, never `pkill -f "next dev"` — that kills other projects too.

== 6. SEE THE WAITLIST OFFER SURFACE
  TOKEN=$(curl -s -X POST http://localhost:8000/api/auth/login \
    -H 'Content-Type: application/json' \
    -d '{"email":"owner@example.com","password":"password123"}' \
    | python3 -c 'import sys,json; print(json.load(sys.stdin)["access_token"])')

  curl -s -X POST -H "Authorization: Bearer $TOKEN" \
    -H 'Content-Type: application/json' \
    -d '{"reservation_time":"<an available slot, ISO 8601 UTC>"}' \
    http://localhost:8000/api/reservations/waitlist/00000000-0000-0030-0000-000000000001/offer

  curl -s -H "Authorization: Bearer $TOKEN" http://localhost:8000/api/reservations/waitlist

  cd /Users/rodinkaradeniz/projects/crowbar/server
  REV=$(docker exec crowbar-db psql -U postgres -d crowbar -tAc \
    "SELECT offer_token_revision FROM reservation_waitlist_entries \
     WHERE id='00000000-0000-0030-0000-000000000001'")
  venv/bin/python -c "
  from uuid import UUID
  from app.services.reservation_waitlist_token_service import issue_offer_token
  print(issue_offer_token(
      business_id=UUID('00000000-0000-0000-0000-000000000002'),
      entry_id=UUID('00000000-0000-0030-0000-000000000001'),
      revision=$REV))"

  http://localhost:3000/reserve/waitlist#token=<the token>
